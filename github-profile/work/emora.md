# Emora

### Multimodal emotion recognition and Arabic creative generation

**Graduation project · Team-built · 2026**

Emora combines EEG and eye-tracking signals to recognize emotions and support Arabic creative experiences for children, including generated stories, images, and spoken content.

## Stack

![Tools](https://skillicons.dev/icons?i=py,pytorch,tensorflow&theme=dark)

**EEG** · **Eye Tracking** · **Multimodal Learning** · **SDXL** · **Gemini** · **Arabic TTS**

## System

```text
EEG + gaze → preprocessing → emotion recognition → Arabic story / art / audio
```

## Research result

The team evaluated recognition across seven emotion classes using leave-one-subject-out validation and reported **45.06% classification accuracy**. This metric applies to the seven-class evaluation, not to generated-media quality.

**Public overview only.** The project was developed collaboratively at Princess Nourah bint Abdulrahman University. Code, recordings and any participant data are not distributed on this page.
