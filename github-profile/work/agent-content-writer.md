# Agent Content Writer

### GitHub activity → Arabic content drafts

A personal automation project that fetches a repository's latest Git commit, asks an LLM to draft a short Arabic update, and saves the draft as Markdown.

![Tools](https://skillicons.dev/icons?i=py,docker,githubactions&theme=dark)

**Python** · **GitHub API** · **Claude API** · **Docker** · **GitHub Actions**

```text
GitHub API → latest commit → LLM prompt → Markdown draft
```

The implementation currently lives in a private repository. This is a draft generator, not an automatic social-media publishing system.
